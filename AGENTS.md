# docs — specification

This file governs spec tasks only. A code task treats this folder as read-only and returns to the
root `AGENTS.md`.

Write only under `docs/<ProductName>/`.

Load the `authoring-bprd` skill and follow it. It owns the document set, order, sections, research,
authorization, and validation; do not restate or improvise them here.

If the skill is unavailable, stop and report. Do not author a specification from memory.

Doc gaps arrive as `doc-gap` issues; resolve them with the user in this folder.

Commit specification changes separately from code. When this folder is a git submodule, the pointer
bump is its own PR.
